# Custom Quick Links

A Chrome extension to quickly access your favorite websites with a customizable toolbar.

## Features

- Add, Edit, Delete links
- Default + custom links
- Dark / Light mode toggle 🌙 / ☀️
- Link icons / favicons
- Shows used links ratio (x/10)
- Extension toolbar icon included

## Installation (Free)

1. Download the repository as ZIP: [Code → Download ZIP](https://github.com/yourusername/custom-quick-links)
2. Extract the folder
3. Open Chrome → go to `chrome://extensions/`
4. Enable **Developer Mode**
5. Click **Load unpacked** → select the extracted folder
6. Extension is ready to use!
